# Python Automation Scripts

A collection of Python scripts I've built for real-world 
automation tasks.

## Scripts included

### 1. Excel Data Cleaner
Reads a messy Excel file, removes empty rows, groups data 
by category, and exports a clean summary report.

**Skills used:** pandas, openpyxl

### 2. Web Scraper
Scrapes product names and prices from any public website 
and saves them to Excel automatically.

**Skills used:** requests, BeautifulSoup, pandas

### 3. File Renamer
Renames hundreds of files in a folder based on a pattern 
in seconds.

**Skills used:** os, shutil
